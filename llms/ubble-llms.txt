# Ubble (Checkout.com Identity Verification)

> Ubble is Checkout.com's identity verification (IDV) solution — video-based identity verification, ID document verification, AML screening, face authentication, and website verification, delivered as the Checkout.com Identities API (api.ubble.ai). Ubble was founded in Paris and is now part of Checkout.com; www.ubble.ai redirects to the Checkout.com Identity Verification product page.

Authentication is HTTP Basic plus mutual TLS (certificates and credentials managed in the dashboard). Webhook notifications use a CloudEvents envelope and are signed with ECDSA/SHA-512 via the Cko-Signature header. Errors use an error_type + error_codes envelope; list endpoints paginate with skip/limit and _links. Resource IDs are formatted {prefix}_{base-32 GUID} (idv_, aplt_, fav_, iddv_, usj_, ...).

## APIs

- [Checkout.com Identities API (v2)](https://docs.ubble.ai/api): 67 operations at https://api.ubble.ai — identity verifications, ID document verifications, AML verifications, face authentications, applicants, business applicants, address/bank/company document verifications, website verifications.
- [Legacy v1 identifications API](https://ubbleai.github.io/developer-documentation/): previous-generation JSON:API reference (changelog ends v1.23, 2022-12-07).
